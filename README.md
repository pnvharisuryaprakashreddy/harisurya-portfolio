# 🌍 Deployment

This project is deployed using **Netlify**.

Steps:

1️⃣ Push project to GitHub  
2️⃣ Login to Netlify  
3️⃣ Click **Add New Site → Import from Git**  
4️⃣ Select the repository  
5️⃣ Deploy
