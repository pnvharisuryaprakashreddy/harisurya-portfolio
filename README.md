# P N V Hari Surya Prakash Reddy — Portfolio

Cloud & DevOps focused developer portfolio with a premium loading experience, smooth interactions, and a clean modern layout.

## Highlights
- Cinematic preloader with animated counter and progress bar
- Responsive layout for desktop and mobile
- Projects, skills, experience, achievements, and contact
- Theme-matched visuals and subtle micro-interactions

## Live
- https://harisurya-portfolio.netlify.app/

## Tech Stack
- HTML, CSS, JavaScript

## Local Preview
```
python3 -m http.server 8080
```
Open `http://localhost:8080`.

## Update Guide
- Main page: `index.html`
- Styles: `style.css`, `css/components.css`
- Loader logic: `js/modules/utils.js`
- Projects: `projects.json`
- Assets: `assets/`
